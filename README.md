# Image Classification using OpenCV

## Overview

A simple image classification project using OpenCV for preprocessing and a machine learning model (SVM / k-NN).

## Tech Stack

* Python
* OpenCV
* NumPy
* Scikit-learn

## Setup

```bash
git clone https://github.com/MinhaMariyamCP/image-classification-opencv.git
cd image-classification-opencv
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Dataset

CIFAR-10 (auto-downloaded in code)
